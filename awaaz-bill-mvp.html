Awaaz Bill 🔊

Awaaz Bill ek voice-powered billing app hai jo kirana/general store ke liye bani hai.

🎤 Mic dabao, item bolo, bill ban jaaye!
🇨🇮 Hindi, English, ya Hinglish mein baat karo.
🖨 Thermal receipt style print karo.

Kaise use karein:
1. Mic button dabayein (ya Space key)
2. Item, quantity aur price bolein
3. "Print karo" ya Print button dabayein

Voice commands:
• "Sugar ek kilo 50 rupaye" — item add
• "Hata do" / "Undo" — last item remove
• "Naya bill" / "Clear" — bill reset
• "Print karo" / "Bill banao" — print receipt

Yeh ek MVP prototype hai. Voice Chrome + Android par kaam karti hai. API key sirf aapke browser mein store hoti hai. Koi data bahar nahi jaata (sirf Claude API ko voice text bhejte hain parsing ke liye).
